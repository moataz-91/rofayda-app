# Rofayda patient app (prototype)

نسخة تجريبية من تطبيق المريض، للتجربة على الموبايل. البيانات فيها تجريبية.

## رفعها على GitHub Pages
1. اعمل Repository جديد (Public) باسم `rofayda-app`.
2. ارفع الملفات اللي في الفولدر ده كلها (Add file → Upload files).
3. من Settings → Pages: اختار Branch `main` وفولدر `/ (root)` واحفظ.
4. بعد دقيقة هيبقى اللينك: `https://<اسمك>.github.io/rofayda-app/`
5. افتحه من Chrome على الموبايل → القايمة (⋮) → Add to Home screen / Install app.
